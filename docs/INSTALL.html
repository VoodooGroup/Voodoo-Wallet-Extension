Install Voodoo Wallet

Chrome extension for PulseChain — download from GitHub and load manually.

1. Download from GitHub

  1. Go to the Voodoo Wallet GitHub repository
  2. Click the green Code button
  3. Click Download ZIP
  4. Save the file to your computer
Download ZIP

2. Unzip the file

  1. Right-click the downloaded .zip file
  2. Choose Extract All…
  3. Open the extracted folder in File Explorer

3. Select the correct folder

GitHub adds an extra wrapper folder. Open the inner project folder, then the dist folder.

📁 voodoo-pulse-extension-main ← WRONG (no manifest) └── 📁 voodoo-pulse-extension-main ├── 📁 dist ← SELECT THIS in Chrome ├── 📁 src └── manifest.json
Rule: the folder you load in Chrome must contain manifest.json.

4. Load in Chrome

  1. Open chrome://extensions
  2. Turn Developer mode ON
  3. Click Load unpacked
  4. Select the dist folder from step 3
  5. Click Select Folder

Pin Voodoo Wallet from the extensions puzzle icon in the toolbar.

Troubleshooting

ErrorFix
Manifest missing / ontbreekt You selected the outer folder. Use the dist subfolder.
MIME type main.jsx You loaded source code. Use the dist folder.
Not from Chrome Web Store Normal for manual installs. Click Keep / Behouden if prompted.
